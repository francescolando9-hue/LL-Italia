# LL Italia — PWA modulare del gruppo

App contenitore a moduli del gruppo MLP / LL Italia. Primo modulo: **Bolle** — fotografare le bolle di consegna in cantiere e inviarle al sistema di magazzino (raccolta SharePoint BolleInArrivo, via endpoint HTTP).

Stack: vanilla JS, HTML, CSS — nessun framework, nessun build step. PWA con Service Worker (offline) e IndexedDB (code dei moduli).
